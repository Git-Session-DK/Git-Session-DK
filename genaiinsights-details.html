GenAI Insights Platform

Transforming Enterprise Data Interaction with AI & Machine Learning

Overview

The GenAI Insights Platform is an enterprise-grade solution that revolutionizes how organizations interact with their data. Leveraging advanced AI and machine learning, it converts natural language queries into dynamic SQL commands – empowering HR professionals and business users to obtain actionable insights quickly and accurately.

Key Features

Natural Language Query Generation

Advanced AI models convert user input into precise SQL queries, reducing manual effort and accelerating decision-making.

Contextual Continuity

Maintains conversation history with a Redis-backed cache to ensure context-aware interactions and refined responses.

Robust Data Integration

Securely connects to enterprise SQL databases using pyodbc with Active Directory Managed Identity for authenticated data retrieval.

Dynamic & Humanistic Responses

Transforms raw query results into user-friendly, HTML-formatted outputs with bullet-point summaries for easy interpretation.

Advanced NLP & Token Management

Employs spaCy, fuzzywuzzy, and tiktoken to optimize prompt management, ensuring precise context and token compliance.

Scalable & Serverless Architecture

Deployed as an Azure Function, the platform benefits from automatic scaling, high availability, and seamless cloud integration.

Architecture Overview

A robust and scalable architecture for GenAI data insights.

Azure Functions

Acts as the entry point for processing HTTP requests and orchestrating workflows.

Azure OpenAI

Generates dynamic SQL queries and humanistic responses using state-of-the-art language models.

SQL Server

Connects securely to enterprise SQL databases using pyodbc with Active Directory Managed Identity.

Redis Cache

Stores conversation history and context as a compressed DataFrame for seamless session management.

NLP & Matching

Extracts keywords and computes similarity using spaCy and fuzzywuzzy.

Prompt Optimization

Uses tiktoken to manage token limits while retaining essential context in prompts.

How It Works

User Input

Submit your natural language query via an HTTP request.

Context Retrieval

Fetch conversation history from Redis.

Query Generation

Azure OpenAI generates multiple SQL query suggestions.

Validation & Execution

Select the best query using fuzzy matching and execute it.

Humanistic Response

Transform raw results into a user-friendly HTML output.

Response Delivery

Return the final JSON response with insights and metrics.
